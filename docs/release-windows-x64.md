PCL CE CN 是第三方基于 PCL CE 独立修改的版本，由本仓库维护。

**本版本仅供学习与交流使用。为便于学习和测试，本分支开启了中国大陆地区的下载功能。**

本版恢复中国大陆地区的 Minecraft 下载、自动安装、加载器及整合包安装、实例修复、重置和启动时缺失文件补全功能，并采用手动更新以避免被上游版本覆盖。

已禁用主仓库及其镜像服务的更新检查、下载和公告。软件只从 [noxargenta/PCL-CE-CN](https://github.com/noxargenta/PCL-CE-CN/releases/latest) 检查更新，下载与更新按钮均导向本仓库发行页。

**下载附件中的 Windows x64 `.exe`，双击即可运行。无需解压，也无需另外安装 .NET；运行时和所需 DLL 已包含在单个程序中，启动时会自动解压到临时目录。**

发行前验证了 Release 配置的地区策略测试，并在只放置此 EXE 的空目录中验证启动及内置 .NET 运行时加载。

本仓库尚未配置微软 OAuth、CurseForge、Natayark 等服务的构建密钥，相关登录或 API 功能可能不可用。

原作者署名和许可证保留在源代码、程序及内置资源中。
